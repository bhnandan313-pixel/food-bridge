# AnnaSetu (FoodBridge)

A platform connecting food donors with NGOs to reduce food waste. 

## Backend Setup
1. `cd backend`
2. `python -m venv venv`
3. `source venv/bin/activate` (or `venv\Scripts\activate` on Windows)
4. `pip install -r requirements.txt`
5. Create a `.env` file (see `config.py` for variables).
6. Run `python app.py`. The server starts on port 5000.

## Frontend Setup
1. `cd frontend`
2. `npm install`
3. `npm run dev`
